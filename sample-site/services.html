Check your chain at home

Between visits, a chain checker tells you when a chain is worn. Here is the rule we use, written as code:

// Chain wear, measured with a checker gauge.
function chainAdvice(wearPercent) {
  if (wearPercent >= 0.75) {
    return 'Replace the chain, and check the cassette.';
  }
  if (wearPercent >= 0.5) {
    return 'Replace the chain soon.';
  }
  return 'The chain is fine.';
}
  1. Shift to the smallest rear cog.
  2. Drop the checker into the chain.
  3. Read the gauge, then run the rule above.
